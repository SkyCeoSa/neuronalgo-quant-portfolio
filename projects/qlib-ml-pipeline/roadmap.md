# Qlib Research Roadmap

This is a public research backlog, not a deployment plan.

## Current public milestone

- [x] Optional dependency separated from the lightweight base environment.
- [x] Sanitized, output-free notebook with explicit local-data prerequisite.
- [x] Documentation of the evidence required before any model-performance claim.

## Possible next experiments

- [ ] Select and document a redistributable/public dataset and version.
- [ ] Define a leakage-safe factor/model protocol and frozen time splits.
- [ ] Add a small configuration-driven experiment that can run without private services.
- [ ] Record baselines, costs, seeds, and sensitivity checks.
- [ ] Export only small, reviewable aggregate results with provenance and limitations.

Live execution, private data, credentials, and production NeuronAlgo integrations remain out of scope.
