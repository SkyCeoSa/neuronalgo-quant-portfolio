# RL Research Roadmap

This roadmap is aspirational and does not describe completed capabilities.

## Current public milestone

- [x] Seeded toy environment with deterministic state transitions.
- [x] Deterministic policy loop and offline smoke test.
- [x] Clear statement that synthetic reward is not financial return.

## Possible research milestones

- [ ] Specify a public observation/action/reward contract before adding a learning algorithm.
- [ ] Add a small redistributable dataset or documented external public-data adapter with no credentials.
- [ ] Define leakage-safe time splits and realistic transaction-cost assumptions.
- [ ] Add baseline policies and multi-seed experiment reporting.
- [ ] Add sensitivity/failure analysis before discussing strategy quality.

Production execution, broker integration, live account connectivity, and private NeuronAlgo systems are outside this public repository's scope.
