# Open-Source Customization Notes

This directory is reserved for **public design notes** about possible integrations or extensions around third-party open-source research tools.

No third-party source code, patched dependency, completed integration, or production NeuronAlgo component is bundled here today. Empty scaffold project folders from the original repository setup have been removed rather than presented as completed work.

If a future customization is added, it should include:

- the upstream project and exact license;
- a link to the upstream source/version;
- a concise description of the public modification;
- reproducible setup and tests;
- attribution required by the upstream license;
- an explicit statement of what remains private or out of scope.

Do not copy private NeuronAlgo services into this directory merely to make an integration appear complete.
